# Original portfolio models

These meshes were created for this portfolio in Blender 4.3.2. They are original assets, not downloaded stock models.

- `stethoscope.glb`: connected silicone tubing, separate binaurals and seals, tension spring, ferrules, two-sided chestpiece, diaphragm, retaining rim and machining lines.
- `hand.glb`: opposed thumb and four articulated fingers, ceramic shells, titanium frame, bearings, hex fasteners, actuator rods, palm plates, wrist and forearm assembly.

Geometry is consolidated by material for about 13 rendered material primitives across both assets. There are no external textures or mesh decoder dependencies. Total uncompressed GLB download size is approximately 2.1 MB.

The source authoring script and editable Blender source are retained in the execution workspace at `/workspace/model-studio/`.
